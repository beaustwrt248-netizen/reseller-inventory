# Beau's Game Inventory

Mobile-first reseller inventory, barcode scanning, Australian pricing lookup, sales tracking and profit dashboard.

## Screens
- Dashboard
- Inventory
- Scanner with camera zoom
- Pricing
- Sales
- Settings

## Data
Inventory and sales are stored in browser `localStorage` on the device. Use the inventory and sales export features for backups.

## Android
Capacitor configuration is included. The GitHub Actions workflow at `.github/workflows/android-apk.yml` builds a debug APK artifact.

Android package ID: `com.beausgames.inventory`.
